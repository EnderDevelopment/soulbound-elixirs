# Minecraft Plugin: Soulbound Elixirs

Soulbound Elixirs is a Minecraft plugin for Paper 1.21.11 that adds collectible soul bottles with unique active abilities and passive powers. Players can receive bottles through the `/soul give` command, hold a bottle to gain its passive effect, and right-click it to activate its original ability.

## Install

1. Use Java 21 or newer.
2. Run a Paper 1.21.11 server.
3. Download the Soulbound Elixirs JAR.
4. Place the JAR in the server's `plugins` folder.
5. Start or restart the server.
6. Operators can use the `/soul` commands by default.

## Use

List all available souls:

```text
/soul list
```

Give a soul bottle to an online player:

```text
/soul give <player> <soul>
```

Available souls:

- `Cinder`: Furnace Pulse ability and Heatproof passive
- `Tideborn`: Undertow ability and Deep Lungs passive
- `Gale`: Updraft ability and Lightfoot passive
- `Rootbound`: Bramble Guard ability and Stone Stance passive
- `Echo`: Resonant Step ability and Keen Hearing passive

Hold a soul bottle in your main hand or offhand to receive its passive effect. Right-click the bottle to activate its ability. Each ability has its own cooldown, and the bottle remains available for repeated use.
